Explain the code in $ARGUMENTS. Cover:

1. **Purpose**: What does this code do at a high level?
2. **Key components**: What are the main functions/classes and their roles?
3. **Data flow**: How does data move through this code?
4. **Dependencies**: What does this code depend on?
5. **Usage**: How is this code used by the rest of the codebase?

Be concise but thorough. Use the actual code structure, not assumptions.
